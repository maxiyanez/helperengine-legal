Política de privacidad

Última actualización: 14 de noviembre de 2026.

"Bandeja Maxi" (Helper Engine) es una aplicación de uso personal de Maximiliano Yañez. La única cuenta que la usa es la de su dueño.

Qué datos usa

Con el permiso de Google gmail.readonly lee los mensajes del correo de su dueño para mostrarle, en una herramienta privada, qué mensajes están pendientes de respuesta. No envía, borra ni modifica mensajes.

Dónde se guardan

Los datos se guardan solo en la computadora del dueño. No se publican, no se venden, no se comparten con terceros y no se usan para publicidad ni para entrenar modelos de inteligencia artificial generalizados.

Uso de datos de las API de Google

El uso y la transferencia de información recibida de las API de Google cumplen la Google API Services User Data Policy, incluidos los requisitos de uso limitado (Limited Use).

Cómo revocar el acceso

El acceso se puede quitar en cualquier momento desde myaccount.google.com/permissions.
